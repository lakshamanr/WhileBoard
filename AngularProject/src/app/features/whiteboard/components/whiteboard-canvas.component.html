Keyboard Shortcuts

  • Ctrl+Z - Undo
  • Ctrl+Shift+Z - Redo
  • Ctrl+C - Copy
  • Ctrl+V - Paste
  • Ctrl+A - Select All
  • Del - Delete
  • Ctrl++ - Zoom In
  • Ctrl+- - Zoom Out
  • Shift+Drag - Pan
  • Double-Click - Edit Text
  • Mouse Wheel - Zoom (towards cursor)

Features

  • Smart Snapping: Auto-aligns elements (pink guides)
  • Connection Handles: Drag from circles on shapes
  • Mini-map: Bird's-eye view in bottom-right
  • Infinite Canvas: Zoom 5%-1000%, pan anywhere
Text Tool: Click to create text, enter your text in the prompt.
Connector Tool:
1. Click first element
2. Click second element to connect
Frame Tool: Drag to create a frame container for organizing elements. Double-click frame title to rename.
