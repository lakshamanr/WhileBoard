Keyboard Shortcuts

  • Ctrl+Z - Undo
  • Ctrl+Shift+Z - Redo
  • Ctrl+C - Copy
  • Ctrl+V - Paste
  • Ctrl+A - Select All
  • Del - Delete
  • Ctrl++ - Zoom In
  • Ctrl+- - Zoom Out
  • Shift+Drag - Pan
  • Double-Click - Edit Text
  • Mouse Wheel - Zoom (towards cursor)

Features

  • Smart Snapping: Auto-aligns elements (pink guides)
  • Connection Handles: Drag from circles on shapes
  • Mini-map: Bird's-eye view in bottom-right
  • Infinite Canvas: Zoom 5%-1000%, pan anywhere
  • Shapes: Rectangle, Circle, Triangle, Line, Connector
Text Tool: Click to create text, enter your text in the prompt.
Sticky Note Tool: Drag to create size, enter text and choose color (yellow/pink/blue/green/orange).
Connector Tool:
1. Click first element
2. Click second element to connect
Or drag connection handles between elements!
Double-click connector to add text label.
Frame Tool: Drag to create a frame, enter custom name. Perfect for organizing board sections into slides or topics.
Line Tool: Drag to draw a line with arrow. Double-click to add text label.
